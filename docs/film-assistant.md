# Filmmaking assistant pilot

The home page is a private filmmaking conversation, with Writing, Direction, Production, Casting and Music focuses. Replies are generated through Vercel AI Gateway using a live-catalog model, openai/gpt-5.4-mini by default. Set AI_GATEWAY_MODEL to override it. Vercel OIDC authenticates the deployed application; local development needs AI_GATEWAY_API_KEY or a linked Vercel development token. Gateway account activation and available credits are required; the app reports a clear configuration/credits error when unavailable. No free or fixed-price chat promise is made.

Requests require the same independently verified owner session as the studio. The route checks request origin, validates role/history/message limits, caps output at 3,500 tokens, uses a 50-second timeout, and disables retries. It offers no executable tools, browsing, booking, media generation or payment actions. Current context uses the most recent 24 messages, up to 48,000 characters; the browser keeps at most 40 messages in the current conversation. Chats and saved briefs are local to this browser and are not cloud-synced conversation archives. Starting a new conversation replaces the current chat; save useful responses as briefs first.

Prepare studio plan performs a separate model call with schema-validated output: a title, story, up to eight characters and up to 12 shots, each two to fifteen seconds. It is an initial sequence, not a promise to generate an entire long film. Review the proposal and explicitly approve the handoff. The backend atomically creates a project and related cast/shots with a zero planning budget; shots stay unapproved and no rendering begins. A stable import ID prevents duplicate films if the network request is retried. Further changes remain available in Film Studio.

The optional frontend/scripts/check-film-ai.mjs makes one tiny real request when explicitly run; ordinary builds do not run it. It logs connectivity and token counts only, without credentials, prompts or provider payloads. These counts are usage, not reconciled billing. Use Vercel AI Gateway usage reporting for charged amounts and team budget settings.
